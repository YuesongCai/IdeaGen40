## 0. 这一版改了什么，以及为什么

v0.3 的问题不是「想错了」，而是**很多规则在它自己的数据口径下无法被执行或无法被检验**。
下表是 v0.4 的全部改动，每一条都是一个具体缺陷加一个具体修法。

| # | v0.3 的问题 | 后果 | v0.4 的修法 | 实现 |
|---|---|---|---|---|
| 1 | D 的分母是「窗口内有效日报份数」，而核心来源只有智堡首页日报（每天 1 份） | 3 日窗口下分母恒为 3，D 只有 4 个取值；`minimum_valid_reports: 5` 永远无法满足，每轮都被标记低置信 | 分母改为**全部 8 条 Wisburg 线的来源条目数**（3 日窗口实测 ~1,600 条）；D 对数标定到当窗口最响的主题 | `scoring.factor_D` |
| 2 | A 用三日覆盖率的加权重心 | 单源下 `c1,c2,c3 ∈ {0,1}`，A 只有 5 个取值，且 (1,0,1) 与 (1,1,1) 同分——恰好抹掉「持续 vs 一次性」这个它要衡量的东西 | 保留重心项（可比性），再混入**强度项**：当日份额在该主题自身过去 20 天分布中的百分位。A = 0.6×重心 + 0.4×强度 | `scoring.factor_A` |
| 3 | B 需要正反两方观点，但策展日报只保留一方；`min(N/4,1)` 系统性打折 | 唯一的「预期差」入口被同向压低，75/60/45 三条绝对门槛整体失准 | 立场编码改为对**全部分层语料**逐条打分（词典公开在 `lexicon.py`）；跨框架争议改为在**来源层级之间**（一手 / 卖方 / 策展）比较净立场，样本门槛从 4 提到 8 | `scoring.factor_B` |
| 4 | N 的「意外程度」要求 `\|实际−一致预期\| ÷ 两年预测误差标准差` | 语料里几乎没有一致预期和历史误差分布 → 该子项长期 NA；按 §12 归一化后，**权重最大的因子里权重最大的子项被静默丢弃** | 意外程度改为**可观测代理**：主题预注册价格指标在窗口内的最大单日涨跌幅 ÷ 自身 60 日日波动。分档表沿用 v0.3。语料若真给出 actual-vs-consensus，则覆盖代理值 | `scoring.factor_N` + `futu_px.move_z` |
| 5 | 「同一机构、同一观点只计一次」无法执行——语料没有机构字段 | 质控条款空转，D 被高估 | 从正文抽取机构名（50+ 家投行/央行/资管的中英文形式）；抽不到时退化为**标题签名**去重，而不是退化为「来源线」（那会重建 8×3=24 格的退化） | `lexicon.institution_of` / `title_signature` |
| 6 | 同一事实可以同时进 D（覆盖度）和 N（新变化） | 双重计分 | **来源分层硬分区**：D/A 只数 Tier 2+3（卖方 + 策展）；N 的因果深度只认 Tier 1+2（一手 + 卖方） | `config.COUNTING_TIERS` / `FACT_TIERS` |
| 7 | 完全没有拥挤度维度 | 一个主题可以 TIS 90 分，而它的表达工具正处在 1 年动量极值，模型不会反对 | 新增独立因子 **C（拥挤度）**＝0.45×60日动量百分位 + 0.30×距 52 周高点 + 0.25×低波动溢价。不进 TIS；高 M + 高 C 触发仓位减半与「等待回踩」 | `scoring.factor_C` |
| 8 | 情景概率与回报可以是纯 `research_judgment` | **不可伪证**：任何结局都与预测相容 | 情景幅度必须落在标的自身已实现波动的 `[0.35σ, 2.60σ]` 带内，否则标记 `narrow` / `wide`，并写进 outcome 供事后检验 | `ideas.vol_sanity` |
| 9 | 不建模任何成本 | 回测系统性虚高 | 佣金 + 滑点双边计入，**在算赔率之前**从三个情景回报里扣掉 | `ideas.net_scenarios` |
| 10 | hurdle 的无风险收益是手工常数 | 与账户真实机会成本脱节 | 取 Olive 美元货币基金货架的**中位 7 日年化**（当前 3.38%）；闲置现金也按此计息 | `ideas.hurdle_for` / `paper._accrue_cash` |
| 11 | 评级门槛是绝对值（保守赔率 ≥ 1） | hurdle 口径一动，全部评级同向漂移 | 保留绝对评级（S/A/B/C）用于可比；并列一个**横截面四分位评级** `grade_rel`，对 hurdle 标定免疫 | `ideas.grade_batch` |
| 12 | 只有价格止损，没有「论点失效」触发 | 宏观前提已被价格否定的仓位会一直留在账上直到价格止损追上 | 新增 `thesis_invalidated` 告警：主题**预注册指标**自建仓以来逆向 ≥ 1.5σ 且仓位尚未触发止损 | `monitor._check_position` |
| 13 | 从不记录结果 | 所有能力主张都无法检验 | 每条 idea 落一条 outcome（含未成交的反事实收益）；输出排序 Spearman ρ、Brier 校准与技能分、按评级/期限/主题/拥挤度/幅度校验分档 | `analytics.settle` / `idea_report` |
| 14 | 没有 as-of 纪律 | 7/23–7/26 的价格被用来定 7/27 执行的进场区间 | briefing pack 里每个价格都来自**已收盘**的交易日；成交只发生在批次生成时刻之后收盘的 bar 上 | `futu_px.complete_through` / `paper.first_fillable` |
| 15 | **主题集合被当成可以提前想全的东西**——16 条主题冻结在代码里 | 实测 **5,836 条语料中 2,688 条（46%）匹配不到任何主题**。盲区里不是边角料：GLP-1 与医保准入、韩国科技股重估、人形机器人、光模块出口管制、央行购金，当时都是活跃且来源充分的真辩论。而固定字典按构造**报不出自己的盲区** | 字典拆成两半：**16 条种子**（代码内，冻结）+ **只能追加的注册表** `themes/registry.jsonl`。每天从零匹配语料里机械挖候选（lift + 篇数/机构/天数门槛 + 共现聚类），由生成器判定后注册。**`registered_d` 不可回填，`all_themes(as_of)` 只返回注册日 ≤ as_of 的主题** | `themes.candidates` / `themes.register` / `lexicon.all_themes` |

**没有改的：** TIS 的四因子权重（0.15/0.25/0.25/0.35）、情景赔率公式、S/A/B/C 的绝对阈值、
主题分级门槛 75/60/45、三层强制层级（主题→传导→资产信号→表达工具）。
保留是为了让 v0.4 的分数与历史 pack 可比。

## 1. 数据口径

### 1.1 来源分层

| Tier | 内容 | Wisburg 线 | 用于 |
|---|---|---|---|
| 1 | 一手 / 原始 | 企业研究、电话会纪要、政策文献 | N 的因果深度、新事实 |
| 2 | 具名卖方 / 资管 | 投行研报、资管研报 | D、A 计票；N 的因果深度 |
| 3 | 策展 / 媒体 | 市场日报、资讯流、研究文章 | D、A 计票 |

3 日窗口实测量级（2026-08-04→08-06）：Tier1 522 条、Tier2 442 条、Tier3 663 条，合计 1,627 条。
其中 D/A 的计票池（Tier2+3）为 1,105 条。对比 v0.3 口径下的 3 条。

### 1.2 按日分页

每条线**按日**独立分页拉取。整窗口一次游标遍历会先截断最旧的一天，
而 A（三日升温）读到的就会是分页假象而不是真实升温。

### 1.3 去重（框架 §12 的可执行版本）

1. `content_hash` 相同 → 只计一次（跨线转载）；
2. 同一机构 × 同一日 × 同一主题 → 只计一次；
3. 机构抽不到时，用标题签名（去标点后前 22 字）代替机构。

实测：1,627 条 → 401 条主题条目，其中 132 条被机构日去重、33 条被标题签名去重，
47% 的条目成功归属到具名机构。

## 2. 主题词典：预注册，但不预先穷举

每个主题固定五件事，读价格之前就定下来：

- `key_question`——预注册的关键结果，一句话，可判真假，**必须含 1–6 个月的期限**；
- `terms`——同义表达词典，至少 4 个写法；
- `price_indicator`——**M 的主指标**，1 个，必须可定价；
- `related`——最多 3 个辅助指标；
- `exposures`——允许的资产信号暴露标签。

### 2.1 为什么不能只有一张固定表

v0.3 要求词典在读取市场表现前冻结，这是对的——否则 M 会自己验证自己。
但它顺带假设了**主题的集合本身可以提前想全**，而这个假设经不起数据检验：

| | |
|---|---|
| 语料总量 | 5,836 条 |
| 16 条种子主题能命名的 | 3,148 条（54%） |
| **匹配不到任何主题的** | **2,688 条（46%）** |

盲区里的内容不是噪声。抽样可见：GLP-1 与医保准入解锁处方量、韩国从工业化到国际化的科技股重估、
人形机器人与美国保护主义、光收发器进口禁令、黄金与韩国央行重启购金、拉美宏观、
电信资本开支追踪、动量与质量因子轮动。全部有具名机构、有多天覆盖，
**全部无法被打分，因此无法产出任何一条想法。**

而最糟的一点是：**固定字典报不出这个数**。它把自己的盲区变成了看不见的东西。

### 2.2 拆成两半

| | 种子主题 | 发现的主题 |
|---|---|---|
| 位置 | `lexicon.SEED_THEMES`，代码内 | `themes/registry.jsonl`，只能追加 |
| 数量 | 16 | 随语料增长 |
| 注册日 | `2026-07-26`（首批之前） | 实际注册的那一天 |
| 版本控制 | 是 | 是（任何改动都是带日期的 diff） |

两半都在版本控制里，所以「读价格前冻结」这条要求没有松动。

### 2.3 唯一真正重要的规则：注册日不可回填

`registered_d` 必须等于注册当天，`lexicon.all_themes(as_of)` 只返回 `registered_d <= as_of` 的主题。

这条规则是整个机制能被信任的全部原因。没有它，「主题发现」就是
**事后挑一个已经涨完的东西定义成主题，然后为自己排序准确而自豪**——
这是所有回看错误里最难被发现、也最能自我欺骗的一种。
有了它，今天注册的主题只能从今天起打分，永远拿不到它没有做过的判断的功劳。

`themes.validate()` 硬拒绝回填；`TestThemeDiscovery` 里有 4 个测试专门守这一条。
开发中它已经抓到过一次真实泄漏：候选挖掘的同义词压制用的是**全部**注册主题而非 as-of 主题集，
于是 SPACE-ECONOMY 在 08-08 注册的那一刻，08-07 的重放就不再把 spacex 当候选了——
历史运行看起来像是「早就发现了」它当时还没看到的东西。

### 2.4 候选怎么挖（机械，不读价格，不做判断）

1. 取 5 日窗口（比 3 日打分窗口宽，要求主题**持续**）里匹配不到任何已注册主题的条目；
2. 从标题挖 CJK 2–6 元字组 + ASCII 词元（不做分词——语料中英混排，
   任何一种分词器都会正好丢掉要找的新词：GLP-1、人形机器人、光模块）；
3. 门槛：≥8 篇 · ≥4 家机构 · ≥3 天 · lift ≥2.0（相对窗口前基线的词频倍数，
   通用套话 lift≈1，真新词 lift 大）；
4. **极大化合并**：丢掉与更长短语共享 ≥80% 文档的碎片。
   滑动字组会把一个短语切成阶梯（维持买入评级 → 持买入评级 → 持买入评），
   只留最长的那一级；
5. **然后**才判定套话：按字符覆盖率 ≥60% 被通用词覆盖即拒绝。
   顺序是承重的——先过滤套话会删掉父短语，让碎片变成孤儿、看起来像高 lift 的新词
   （第一版就是这样让「持买入评」连续四天登上候选榜首的）；
6. 按共现文档聚类（Jaccard ≥0.34），聚类后 ≥10 篇才输出。

### 2.5 候选不等于主题

第 4 步之后仍会漏进三类噪声，**这是设计上的分工，不是缺陷**：机械挖掘负责
「这些文档在讲一个字典没有词的东西」，语义判断留给生成器。

| 噪声类型 | 实测例子 | 为什么不注册 |
|---|---|---|
| 单个公司 | 小米集团、亚马逊、苹果 | 一家公司不是宏观主题 |
| 研报系列名 | skynomad | 是栏目名，不是辩论 |
| 泛词碎片 | 下一 | 语义太薄，注册后会匹配大量无关文档 |

判定标准一条：**这个词命名的是一个「未来 1–6 个月会有答案、且有可交易工具能表达」的分歧吗？**

已注册的两条（2026-08-08）：

| id | label | 关键问题 | 主指标 | 证据 |
|---|---|---|---|---|
| `FACTOR-ROTATION` | 因子轮动与拥挤交易解除 | 从动量与 AI 拥挤交易向价值与防御的轮动能否延续 | `US.VLUE` | 11 篇 / 10 家 / 3 天 / lift 2.30 |
| `SPACE-ECONOMY` | 商业航天与卫星产业化 | 商业航天订单与首批财报能否支撑估值扩张 | `US.XAR` | 16 篇 / 9 家 / 4 天 / lift 6.03 |

### 2.6 冷启动与休眠

新主题没有自己的 20 天历史，A 的强度项算不出来，当天记 `cold_start=true`。
这个标记进归因分档，**所以「发现的主题是不是系统性更差」是一个可测量的问题**，
而不是一个看不见的问题。

连续 20 个已打分日无证据的主题标 `dormant`，不再分配配额。**不删除**——
过去的 outcome 引用它，而且一个沉寂一个月的主题回来时，往往是账本里最值得看的东西。

### 2.7 每天都要看的数

`coverage_pct` = 当天语料里至少命中一个主题的比例，当前约 **54%**，
显示在看板「当日语料底稿」折叠区、`ideagen sources` 与 `ideagen theme-candidates`。
这个数字**下降**意味着发现机制跟不上语料了。

## 3. 因子公式

### 3.1 Tactical Impact Score（不变）

```
TIS = 0.15·D + 0.25·A + 0.25·B + 0.35·N
```

任一因子缺失时按剩余权重归一化，并在 `factors.TIS.missing` 里列出。

### 3.2 D 讨论覆盖

```
raw_t   = 主题 t 在 Tier2+3 里去重后的条目数
max_raw = 当窗口所有主题里最大的 raw
D_t     = 100 × ln(1+raw_t) / ln(1+max_raw)
```

用对数而非线性份额：跨主题的注意力分布是重尾的，
线性份额会把所有主题压到 10 分以下。D 因此是「相对当窗口最响的主题有多响」。

### 3.3 A 三日升温

```
c_k      = 第k日提及条目数 ÷ 第k日计票池条目数        (k=1,2,3)
重心      = (1·c1 + 2·c2 + 3·c3) ÷ (c1+c2+c3)
tilt     = 50 × (重心 − 1)
强度      = 该主题 c3 在自身过去 20 天 c3 分布中的百分位
A        = 0.6 × tilt + 0.4 × 强度
```

基线不足 8 天时强度记 NA，A 退化为 tilt 并标注。
系统运行满 20 天后强度项才完全生效——这是 30 天窗口的一个真实约束。

### 3.4 B 关键争议

```
方向争议 = 100 × 4 × p₊ × p₋ × min(方向明确条目数 ÷ 8, 1)

跨框架争议 =
  100  ≥2 个独立来源层级的净立场明确对立
   70  两类来源结论相反，传导链待验证
   40  同层级内 ≥2 家机构看多且 ≥2 家看空
   40  方向分布接近对半但无跨层级对立
   10  仅条件差异
    0  方向一致或无方向明确观点

B = 0.65 × 方向争议 + 0.35 × 跨框架争议
```

### 3.5 N 最新变化

```
新事实广度 = 100 × min(Tier1+2 里 (机构, 事实类型) 去重对数 ÷ 6, 1)
意外程度   = 分档(z)，z = 主指标窗口内最大单日 |涨跌幅| ÷ 自身60日日波动
             z<0.5→20  0.5–1→40  1–1.5→60  1.5–2→80  ≥2→100
因果深度   = Tier1+2 里最重要 3 条事实的深度均分
             100 已实现利润/现金流/正式政策行动
              75 新订单/营收/融资条款
              50 市场价格显著变化
              25 叙事或意向

N = 0.30 × 广度 + 0.40 × 意外 + 0.30 × 深度
```

广度按「(机构, 事实类型) 对」而不是文档数计——
一家机构就同一事件发五篇不会被读成五条新事实。

### 3.6 M 市场验证（独立，不进 TIS）

```
M = 0.40 × 方向命中率 + 0.30 × 幅度百分位 + 0.30 × 广度
```

方向取自**语料净立场**，绝不取自价格——否则 M 会自我验证。
分段：0–29 尚未定价 / 30–59 早期验证 / 60–79 已有确认 / 80–100 交易成熟。

### 3.7 C 拥挤度（新增，独立）

```
C = 0.45 × 60日动量百分位
  + 0.30 × 距52周高点得分（-3% 内满分，-20% 外 0 分）
  + 0.25 × (100 − 20日已实现波动百分位)
```

第三项刻意反向：**高位 + 安静**才是典型的拥挤形态。
分段：<35 不拥挤 / 35–60 中性 / 60–80 偏拥挤 / ≥80 高度拥挤。

C ≥ 80 时，该主题下的想法强制 `等待回踩` 且 `pos_init` 减半。

## 4. 入选与配额

进入正文（`selected_theme_ids`）需同时满足：

```
独立机构数 ≥ 3
覆盖来源线 ≥ 2 类
计票池条目 ≥ 12          （v0.3 的 minimum_valid_reports: 5 改为条目口径）
TIS ≥ 45
```

最多 6 个主题。40 条 idea 的配额：入选主题每个 4–8 条，watch 级每个 1–3 条；
同一 `signal_id` ≤ 3 条；同一标的只出现一次；同一主题合计仓位 ≤ 25%。

## 5. 情景与赔率

### 5.1 公式（不变）

```
Expected Return       = Σ Pₛ·Rₛ
Expected Gain Above H = Σ Pₛ·max(Rₛ−H, 0)
Expected Loss Below H = Σ Pₛ·max(H−Rₛ, 0)
Opportunity Ratio     = Gain ÷ Loss
```

### 5.2 hurdle

```
rf_annual = Olive 美元货币基金货架中位 7 日年化      （当前 3.3796%）
lp_annual = 按工具类型：ETF/股票 0，公募 0.4%，UCITS 1.2%，私募/结构化 2.0%
hurdle_pct = (rf_annual + lp_annual) × 月数 ÷ 12 × 100
```

### 5.3 成本（新增）

```
往返成本% = 2 × (佣金bps + 滑点bps) ÷ 100
  US 上市：2 × (1.0 + 3.0) / 100 = 0.08%
  HK 上市：2 × (2.5 + 5.0) / 100 = 0.15%
  基金：0（申赎按 NAV）
```

**在算 Gain / Loss / OR 之前**从三个情景回报里扣掉。

### 5.4 情景幅度校验（新增）

```
σ_h    = 标的自身已实现年化波动 × √(月数/12)
k_up   = |R_up|   ÷ σ_h
k_down = |R_down| ÷ σ_h
要求 0.35 ≤ k ≤ 2.60，否则记 narrow / wide
```

不因此否决任何 idea——但标记会写进 outcome，
用来回答「情景写得夸张的想法是不是真的更差」。

### 5.5 评级

```
绝对（沿用 v0.3）：保守赔率 ≥1.5 → S；≥1.0 → A；中心赔率 ≥1.0 → B；否则 C
相对（新增）：      同批次内保守赔率的四分位 → Q1（最好）/ Q2 / Q3 / Q4
```

## 7. 模拟盘执行规则

两个组合共用同一批 idea，差别只在执行方式：

| | 守纪律组合 | 无脑全买组合 |
|---|---|---|
| 仓位 | `pos_init% × 评级乘数`，单标的 ≤5%，单主题 ≤25%，总敞口 ≤100% | 等权 |
| 进场 | 进场区间限价 / 突破触发 | 首个可成交收盘价 |
| 止损 | 收盘价 < thesis stop | 无 |
| 止盈 | 盘中最高价 ≥ take_lo | 无 |
| 到期 | 到期收盘平仓 | 到期收盘平仓 |
| 未成交资金 | 留现金，按货币基金收益计息 | 无 |
| 评级乘数 | S 1.25 / A 1.00 / B 0.75 / C 0.40 | 不适用 |

成交规则：

- **不可同 bar 回看**：只能在批次生成时刻**之后收盘**的 bar 上成交；
- **限价成交取较差价**：买入限价挂在区间上沿，成交价 `min(区间上沿, 开盘价)`；
- **突破次日开盘成交**：t 日收盘确认，t+1 日开盘成交；
- **双边计成本**；
- **不可盯市的标的绝不进组合**：记录、告警、从 P&L 剔除并单独披露。

## 9. 事后检验（v0.3 完全缺失的部分）

每条 idea 落一条 outcome，含未成交的反事实收益，然后输出：

- **排序能力**：中心赔率 / 保守赔率 / 中心 EV 与实际收益、超额收益的 Spearman ρ；
- **概率校准**：三分类 Brier，对照均匀先验（0.6667）给技能分 `1 − Brier/0.6667`；
- **情景实现分布**：实际落在 up / base / down 的比例，与声明概率对照；
- **分档**：绝对评级、相对分位、期限、主题、工具类型、情景幅度校验、是否成交；
- **敞口匹配基准**：以组合自身平均净敞口持有 SPY、其余现金——
  剔除仓位规模后的纯选股读数。

## 10. 仍未解决 / 后续校准

1. **A 的强度项需要 20 天基线**——系统运行满 20 天前该项为 NA。
2. **B 的立场编码是词典法**，不是语义理解；反讽、条件句、双重否定会误判。
   下一版应把立场编码交给生成器并要求逐条给出理由，机器值作为先验对照。
3. **意外程度的价格代理会把「市场已反应」误读为「有新意外」**——
   它和 M 有结构性相关。需要在 30 天样本上测两者的相关系数，
   若过高则应从 N 中剔除、只保留在 M。
4. **Olive 基金只有当日 NAV，没有历史序列**——
   基金类 idea 的日频曲线从系统上线日开始累积，无法回溯。
5. **OpenD 历史 K 线有滚动 30 天不同标的额度**（本账户已用满 90 个），
   宇宙扩张受此约束，被挡的标的会自动标记为不可盯市。
6. **四因子权重、拥挤度分段、情景波动带上下界**都还是先验值，
   需要在积累样本后用 outcome 数据校准。
7. **A股无行情权限**，中国主题只能用离岸（MCHI/KWEB/FXI）与港股表达。
