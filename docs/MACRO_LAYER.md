# 宏观层：从「拿到了」到「接到了哪个决定上」

2026-09-05。`feeds_impl/calendar_fmp.py` 与 `positioning_fmp.py` 把四类新行放进
`events`：带一致预期的宏观发布、波动率指数复合、美债曲线、CFTC 期货持仓。
它们全部到达**生成器**，作为 prompt 文本。在 `ideagen/macro.py` 之前，
它们**没有一条到达因子、进场区间或期次记录**。

一个源接进来而不接到某个决定上，产出的只是更长的 prompt。这份文档写的是另一半。

---

## 判据

初心里写着「信息源 credible/stable 够了不用多」。而 2026-09-05 那轮挖出来的
病灶是：`disciplined` 383 张单里 264 张过期未成交（69%），六期平均只投出
72.2%；`ev` 排序一阶上是一条波动率阶梯（末位桶年化波动 5.3%，顶格桶 33.6%）。
**再加六个信号，这三条一条都不会好。**

所以只有两类值得接：

1. **补上代码自己写着的洞** —— `scoring.factor_N` 的文档原文说 surprise 项
   因为「the corpus does not carry consensus or a forecast-error distribution」
   而退化成价格代理；
2. **提供一个不从价格来的视角** —— `factor_C` 现在三条腿全部来自 `futu_px`。

其余的进展示层，或者不进。

---

## 三个接口

### 一致预期 → `factor_N`

`factor_N(consensus_z=…)` 这个参数从 v0.4 起就在，**从来没有调用方传过值**。
两个缺失的半边现在都有了：FMP 的 `economic-calendar` 同时给 `estimate` 和
`actual`；同一个端点拉两年得到 `(actual − estimate)` 的分布，就是 v0.3 要的那个除数。

**归因走价格，不走名字。** 把发布名去匹配主题词表，正是 `lookthrough` 花代价
移除过的那个 join —— ITA / PPA / XAR 都写「国防军工」，实际对同一批标的的权重是
53% / 45% / 26%。所以 `theme_consensus_z` 取的是：**主题自己预注册的价格指标在
窗口内波动最大的那一天，当天结算的那条发布的 surprise**。指标是事前注册的，
事后选不了；当天没有结算发布，就退回今天的行为。

意义在于把「有意外发生」和「价格动了」分开：**在所有数据都如预期的那天出现的
2σ 波动，不是关于这个主题的新信息，而今天它按新信息计分。**

误差分布的守卫：
- 少于 8 次已结算，标 `underpowered`，**不给 z**（三个观测算出来的 sd 是一个数，不是一个分布）；
- sd 为 0 标 `degenerate`（那意味着厂商在把预期当实际回填，不是经济是确定性的）；
- 「这条发布结算了但我们没有尺子去判断它」和「这周没有这条发布」是两件事，
  `window_surprises` 两种都返回，只是一个带 `z`、一个带 `why`。

### CFTC 持仓 → `factor_C`

`factor_C` = 0.45 × 动量分位 + 0.30 × 距 52 周高点 + 0.25 × 平静度。
三条腿全部读价格序列。而「`ev` 排序一阶上在排波动率」这个结论**也是从价格得出的**
—— 同一条序列的第四个视角，会因为与前三个同源而同意它，这跟拥挤度无关。

CFTC 投机净多占比是这里唯一的非价格拥挤度，而且它覆盖的正是
COPX / USO / GLD / TLT 背后的合约 —— `robustness_drop_top` 指认为「拿掉就优势归零」
的那批名字。**所以它能证伪那个结论，或者证伪不了，两种都比第四个价格视角值钱。**

映射按链路强度分两级，因为这是两种不同的断言：

| 链路 | 含义 | 权重 |
|---|---|---|
| `direct` | 基金的敞口**就是**那个期货（CPER→HG、TLT→ZB、UUP→DX） | 0.25 |
| `proxy` | beta 关系（COPX 是铜矿股，不是铜） | 0.15 |
| `none` | 不硬映射 | — |

**故意留空的比映上的更说明问题**：DBC / PDBC 是没有单一合约的宽基商品篮子；
VLUE / QUAL / MTUM 不是标普（VLUE 按权重 21% 是半导体）。
为了提高覆盖率把它们映到 ES，就是这个系统已经花代价移除过的那种标签断言。

### 隐含波动率 → 进场区间

`db.py` 的列注释自己写着 `sigma_h REAL -- horizon **realised** vol used for the
sanity band`。而钱是在区间上丢的：264/383 张单过期未成交，那是**宽度**问题。
用回望 60 天的数去画未来 30 天的区间，本来就是错配。

FMP 这把 key 上**没有任何期权数据**（`options-chain` 等五条路径全 404），所以
隐含波动率只能以指数形式到达 —— 而这恰好对：这个组合持的是 ETF 对宏观论点，
不是单名微笑。^VIX / ^VXN 给股票，^MOVE 与 ^VXTLT 给利率（这个 mandate 交易最多的
资产类），^OVX 给原油，^GVZ 给黄金。

**只放宽，不收窄。** 缺陷是单向的（区间太窄），所以补救也是单向的。
无条件采用隐含值会在某些标的上**收窄**区间 —— 那是第二个、方向相反的赌注，
没有证据支撑，而且是悄悄下的。

映射的质量是**可测的**：`ratio_to_realised` 进每条 idea 的元数据。
TLT 对 ^VXTLT 应该落在 1 附近；映错了，比值会漂，第一期就说出来，
不需要谁去手工审这张字典。

## 状态记录：接到「没有」上

`regime()` 是第四件事，也是唯一一件**故意不接到任何地方**的。

参照实现的那张牛熊带状历史，13 个月里几乎整条读同一个值。
**一个九成时间不变的状态变量，在只有 6 期的样本上没有方差可贡献**，
拿它做闸门就是换了身好看衣服的 multiple testing。

所以它返回各腿的水平，**拒绝给结论**：没有综合分，没有牛熊标签。
一个数字会立刻招来它想推迟的那个闸门，而后面真要做的条件回归要的本来就是分腿的水平。
每天一个 kv 键 `macro:regime:<date>`，攒的是序列。

---

## 开关：接进来 ≠ 打开

三个接口**默认全关**。它们都是打分或模型输入，中途打开会让第 7 期与前 6 期不可比 ——
和 `IDEAGEN_UNIVERSE_LOOKTHROUGH` 默认关是同一个理由，而前 6 期是目前全部的证据。

| 开关 | 打开后 |
|---|---|
| `IDEAGEN_FACTOR_N_CONSENSUS` | N 的 surprise 用一致预期偏离，而不是指标自身波动 |
| `IDEAGEN_FACTOR_C_POSITIONING` | C 混入 CFTC 持仓腿 |
| `IDEAGEN_SIGMA_IMPLIED` | 区间的 σ 取 max(已实现, 隐含) |

**关着的时候仍然记录反事实**，这是让开关变得可决策的那一半：
`factor_C` 每期同时记 `score_price_only` 和 `score_with_positioning`；
每条 idea 都存下隐含波动会怎么说它的区间。
几期之后，「开了会不会有区别」这个问题的答案是这本组合自己的数字，而不是争论。

切换建议：**换期那天一次性切**，并在期次坐标上标一条「输入变更」线，
让以后任何人看到跨线的比较都知道两边不同源。

## 怎么跑

```
ideagen macro status                 # 先跑这条：哪些开关开着，events 里有什么
ideagen macro refresh                # 拉四个 feed 落库 + 拟合误差分布 + 记状态
ideagen macro refresh --force        # 强制重拟合（9 次调用，约 7 分钟）
ideagen macro surprises --days 14    # 近两周结算的发布与各自的 z
ideagen macro positioning            # 每个标的的合约、链路强度、COT 滞后天数
ideagen macro regime                 # 当日各腿水平（无结论，按设计）
```

日更管线里它是 `[4/10]`，**在 `score` 之前**。位置不是随意的：
因子读 `events`，一个读到今早没人填过的表的因子不是「降级」，
它是在拿上次写表的时候的数当今天的答案自信作答 —— 这正是这个仓反复找到的那种缺陷形状。
误差分布最多 7 天重拟一次（`STATS_MAX_AGE_DAYS`），分布是以年为尺度动的。

## 第一次真跑抓到的两件事（都不是崩溃，都是会被相信的数）

### 一、参考期被写进了发布名里

FMP 的 `event` 字段长这样：`Core PCE Price Index YoY (Jul)`、
`GDP Price Index QoQ (Q2)`、`Initial Jobless Claims (Aug/22)`。
按原名做键，**每一次发布都是一条 n=1 的独立序列**。

第一次两年拟合的结果是 **2375 条序列，1 条可用**。
这个数读起来正好像「这家厂商很少发一致预期」，而事实完全相反 ——
修掉之后是 **158 条序列，145 条可用**。

没有任何东西报错，数字也足够可信到会被直接采纳。
所以 `_series_name()` 只剥**期次形状**的后缀，
`(Final)` / `(Prel)` / `(Adv)` / `(Flash)` 一律保留 ——
初值和终值的误差尺度本来就不同，把它们并成一条分布是反方向的同一个错，而且更安静。

### 二、「窗口内波动最大的那天」总能选出一天来

第一次对真数据跑归因，`TERM-PREMIUM` 在指标只动了 **0.34σ** 的情况下，
拿到了当天非农 **+1.35σ** 的全部 surprise；`POLICY-PATH` 是 0.38σ。

**这正是价格归因本该防住的那种归因，却是从归因本身进来的。**
所以加了 `MIN_REACTION_Z = 1.0`：主题的指标当窗口没有真的动过，
就不把那天的意外算作它的新闻，退回今天的行为。

## 已知边界

- **单名期权拿不到，两条路都验过**：FMP `options-chain` 连试三次 404；
  Futu OpenD 端口通着但账户返回「No permission to get quotes for US.AAPL…
  US MarketStocks quote permissions」—— 连美股行情权限都没有（历史 K 线是另一项权限，
  所以日线照跑）。这是采购决定，不是工程任务。
- **情绪端点这把 key 上全 404**：`social-sentiments` / `historical-social-sentiment` /
  `fear-and-greed` / `market-sentiment`。而 B 因子已经在对分层研报做立场编码，
  那个有出处、可追问，比外部社媒情绪值钱。
- **国会披露交易只做展示**：`positioning_fmp` 已经按板块汇总并自报集中度，
  行标签里带着「金额取披露区间中点，非精确值」，`priority: 3`。
  它**不进任何因子**：中位披露滞后 35 天（最长 119），而持有期是 30 天 ——
  信号在能看到之前就过期了。
- **传输错误和权限错误长得几乎一样**。第一轮探测里
  `biggest-gainers` / `analyst-estimates` / `etf/holder` 都报
  `SSL: UNEXPECTED_EOF`，那是本机代理掐的；重试后前两个正常，只有 `etf/holder`
  是真 404。**判断某个端点「没有」，要重试到稳定再下结论。**
