# 来源口径诊断：只用「智堡日报」会让四个因子失真到什么程度

**诊断对象：** `战术宏观主题评分框架_v0.3.md` 第 2 节（报告范围）与第 13 节（当前默认参数）
**日期：** 2026-07-28 HKT
**性质：** 只诊断，不修改方法论。文末的建议未写入任何版本。

---

## 0. 一句话结论

问题不在于「日报不够」，而在于**框架把一个多层数据源当成单层在用**：v0.3 只调用了智堡的「首页日报」这一条线，而 D 和 A 两个因子的分母就架在这条线的**日频份数**上。结果是占 40% 权重的 D + A 退化成一个 20 格的查表，占 35% 权重的 N 又恰好最依赖日报给不了的一手数据。

---

## 1. 框架现在的来源设定

摘自 v0.3 §2：

| 角色 | 来源 | 用途 |
|---|---|---|
| 核心 | 智堡首页日报 | 主题识别、D、A、B、N 的证据池 |
| 补充 | 华尔街见闻 | 事件时点、市场反应、价格变化 |
| 核验 | 央行、统计机构、公司公告、发行人资料、具名投行原文 | 事后核对 |

关键参数（§13）：`observation_window_complete_report_days: 3`、`minimum_valid_reports: 5`、`minimum_theme_sources: 3`。

**这里已经有一处内部冲突：** 窗口是 3 个完整日报日，而最少有效日报数要求 5 份。若「日报」按份数计，智堡首页日报是每日一份产品，3 天最多 3 份 —— **恒定小于 5**，按 §5.1 每一轮都必须给 D 打上「低置信度」。这条门槛在现行口径下永远不可能被满足。

## 2. 逐因子失真

### 2.1 D 讨论覆盖（权重 15%）

```text
D = 100 × 提及主题的独立日报数 ÷ 当前窗口有效日报总数
```

分母 = 3 时，D 的取值集合只有 **4 个**：

| 提及天数 | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| D | 0 | 33.3 | 66.7 | 100 |

15% 的权重挂在一个四档变量上。两个主题只要都「三天提了两天」，D 就完全一样，没有任何区分度。

### 2.2 A 三日升温（权重 25%）—— 退化最严重

每天只有一份日报时，`c1 / c2 / c3` 只能取 0 或 1，代入

```text
A = 50 × [ (1·c₁ + 2·c₂ + 3·c₃) ÷ (c₁ + c₂ + c₃) − 1 ]
```

穷举全部 8 种组合：

| (c₁,c₂,c₃) | 加权重心 | A |
|---|---:|---:|
| (1,0,0) | 1.00 | **0** |
| (1,1,0) | 1.50 | **25** |
| (1,1,1) · (1,0,1) · (0,1,0) | 2.00 | **50** |
| (0,1,1) | 2.50 | **75** |
| (0,0,1) | 3.00 | **100** |
| (0,0,0) | — | 0（§6 规定） |

也就是说：**A 只能取 {0, 25, 50, 75, 100} 五个值**，并且完全由「哪几天提到了」决定，与「讨论有多密集」无关 —— 而 A 的设计意图恰恰是衡量密集度。25% 的权重变成了一个五档开关。

§6 那句「三日中间出现一次脉冲、随后消退时，分数会回到中性附近」在多源下成立，在单源下退化为 (1,0,1) 与 (1,1,1) 同为 50 分 —— 「持续讨论」和「首尾各提一次」不可区分。

**D 与 A 合计 40% 的权重，联合起来只有 4 × 5 = 20 种取值组合。**

### 2.3 B 关键争议（权重 25%）

```text
Directional Debate = 100 × 4 × p₊ × p₋ × min(方向明确观点总数 ÷ 4, 1)
```

两处系统性偏低：

1. **样本折扣**：单一策展源的三天里，围绕同一个预注册关键结果、方向明确且可拆成独立观点的条目，很难凑到 4 条 → `min(N/4, 1)` 几乎总在打折；
2. **跨框架争议拿不到证据**：§7.2 满分档要求「至少两组独立框架明确对立，且指向同一标的或同一因果链」（如股票分析师看盈利弹性 vs 信用分析师看再融资）。这类对立存在于**投行研报原文和电话会纪要**里；日报做的是摘要，通常只保留一方结论。

B 是整个框架里唯一的「预期差」入口，它系统性偏低会直接压低所有主题的总分，且是同向压低 —— 不影响排序，但会让 75 / 60 / 45 三条绝对门槛整体失准。

### 2.4 N 最新变化（权重 35%）—— 权重最大、来源最不匹配

```text
N = 30% × 新事实广度 + 40% × 意外程度 + 30% × 因果深度
```

- **意外程度**要求 `Surprise Z = |实际值 − 一致预期| ÷ 过去两年同类预测误差标准差`。日报很少同时给出实际值、一致预期和历史预测误差分布 → Z 常常算不出来；
- **因果深度**的两个高档（75 分「订单、收入或融资条款」、100 分「利润、自由现金流或正式政策行动」）需要一手财报、公告、政策文本；日报的叙事转述天然落在 25 分（叙事或意向）到 50 分（市场价格）区间。

按 §12「任一因子缺失时显示 NA，并按剩余权重重新归一化」，意外程度缺失就意味着 N 实际退成 `广度 : 因果深度 = 30 : 30 → 各 50%`。**占总分 35% 的主因子，长期在缺一个子项的状态下运行，而且缺的是权重最大的那个子项（40%）。**

### 2.5 共同源偏差

智堡首页日报本身大量是对海外投行研报的编译与策展。多份日报（或同一日报的多个条目）提到同一主题，很可能回溯到同一份原始研报。

§12 已经写了「同一机构、同一观点只计一次」「媒体转载回溯原始来源」—— 但**如果证据池里只有日报这一层，就没有可回溯的对象**，这两条质控无法执行。后果是 D 被高估、A 与 D 同向漂移。

## 3. 你其实已经买到了更多层

智堡站上公开列出的产品线（首页「研究引擎覆盖」，标注 AI 每日投研笔记 **超 50 篇 / 天**）：

| 线 | 与框架的对应关系 |
|---|---|
| 全球投行研究资讯 | B 的跨框架争议原料（同一标的的股票 / 信用双向观点） |
| 全球市场新闻快讯 | D / A 的计票池，能把分母从 3 提到远超 `minimum_valid_reports: 5` |
| 政策研究文献 | N 因果深度 100 分档（正式政策行动）的原料 |
| 市场热点图表 | §11.1 要求固定嵌入的 4 张智堡原始图表；同时是 M 的价格证据 |
| 头部企业电话会纪要 | N 因果深度 75–100 分档（订单、收入、利润兑现）的**唯一**日频原料 |

框架当前只用了第一条线的日报形态。**每一个失真点，都能在这张表里找到对应的补料。**

## 4. 失真的净效果

| 因子 | 权重 | 单源下的实际状态 |
|---|---:|---|
| D 讨论覆盖 | 15% | 4 档；且恒定触发「低置信度」标记 |
| A 三日升温 | 25% | 5 档；密集度信息完全丢失 |
| B 关键争议 | 25% | 被 `min(N/4,1)` 系统性打折；跨框架档位基本拿不到 |
| N 最新变化 | 35% | 意外程度长期 NA，归一化后只剩两个子项 |

Tactical Impact Score 显示到小数点后一位，但在单一日报源下，它的**有效分辨率远低于显示精度** —— 分差 5 分以内的两个主题基本不可区分。而分级门槛恰好卡在 75 / 60 / 45，落在门槛附近的主题，其等级更多由 A 的五档跳变决定，而不是由主题本身的强弱决定。

## 5. 如果要修（未写入任何版本）

按代价从低到高：

1. **先消歧义**（一句话的事）：把 §5.1「有效日报总数」明确成「有效**来源条目**数」还是「日报份数」。这一句决定 D 和 A 是否退化 —— 目前两种读法都成立，而两种读法给出的分数完全不同。
2. **给 N 单开事实池**：把电话会纪要和政策研究文献纳入 N 的新事实来源，但**不进 D 的分母**（避免同一事实在覆盖度和新变化里双重计分）。这是收益最高、对现有公式改动最小的一步。
3. **来源分层**：Tier 1 一手（央行 / 统计 / 公告 / 电话会）、Tier 2 具名投行研报、Tier 3 策展与媒体。D 和 A 用 Tier 2 + Tier 3 计票，N 的因果深度只认 Tier 1 + Tier 2。§14「后续校准」第 4 条已经把「来源质量是否分层加权」列为待校准项 —— 这条其实是前置条件，不是可选优化。
4. **修 `minimum_valid_reports`**：要么把它降到与 3 日窗口自洽的水平，要么把分母换成条目数。现状是一条永远无法满足的门槛。
