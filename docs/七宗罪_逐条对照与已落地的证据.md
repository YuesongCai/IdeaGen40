## ① 幸存者偏差

**论文**：只用「今天还在的公司」回测，会得到过分乐观、甚至符号相反的结论——
用幸存宇宙测 Merton 距离违约，最差信用质量反而跑赢 7 倍。

**本仓**
- 新增侧早有：`instruments.first_seen_d` + `universe.eligible(as_of=)`。
- 删除侧 2026-09-06 才有：`shelf_departures` 表 + `shelf_store.persist` 的快照差分
  （回来的盖 `returned_as_of` 不删行；按 source 比，否则一次 fixture 会凭空造出上百条下架）。
  `backtest.context_for` 加了对称闸 `departed_by`。
- **实测现状是最坏的那个**：`shelf_snapshots` 只有 1 张（2026-09-05，151 只），
  `point_in_time_from = None`。

**还不能说**：不能说历史期的可选标的是当期的那一张货架。**它就是今天这张。**
从第二张快照起才开始积累。面板「货架体检 → 下架记录」上印着这句。

## ② 前视偏差

**论文**：用当时拿不到的数据。财报要滞后 1–2 个月；用非 PIT 数据会把盈利收益率因子
的表现抬高约 60%。

**本仓**
- 有：as-of 钳制（研报/行情/日历/候选池四条，`backtest.Audit` 逐条报）。
- 2026-09-06 补上第五条：**可选标的**。`eligible(as_of=)` live 在调、回放不调，
  而且 `_universe` 建出来的行根本不带 `first_seen_d`，调了也是空转。
  实测 2026-07-29 期：306 → 133（1 个当期未上架，其余是 live 本就在用的载体授权过滤，
  即**回放此前比 live 宽**）。放行名单里还留着晚于 as_of 上架的标的 = 泄漏，strict 下拒绝。
- 已量化过的一次真实污染：`ev_rank` 是 09-05 事后设计却在 07-29 起的数据上评估，
  前推检验量出 **2.07pp**，比全部表面优势还大。

**还不能说**：不能说补跑期没有前视——权重没见过未来，但**人的后见之明**是同一回事。

## ③ 讲故事

**论文**：找到模式之后总能编出解释，而「能解释」和「样本外能不能赚」无关；
还有确认偏误，和「历史多长才够」——价值因子在科技股上 20 年几乎零收益、
两段两年半分别是 −70% 和大幅回升。

**本仓**：生成器本身是一台产故事的机器，所以解药只能是主动证伪。目前三层：
1. 波动率控制：ρ(ev, 入场前 60 日波动) = **+0.686**；控波动后偏相关 +0.008 (t=0.07)。
2. 剔除头部标的：拿掉最常持有的 20 个，优势归零。
3. **换 universe（本轮新增）**：见 ④。

**还不能说**：本仓全部证据落在**同一个上涨 regime**里（6 期 live / 105 个回放期 / 27 个交易日净值）。
论文要求跨多个经济周期。所以任何结论的上限是「值得往前跑一段看看」。

## ④ 数据挖掘与数据窥探

**论文**：试得够多总能找到样本内极好的东西；对策是——只用当时可得的数据、
**回测一套固定规则而不是一个个因子**、**同一套方法换一个 universe 原样跑**、
**留一份从没碰过的 validation sample**、以及看真实的向前表现。

**本仓**
- 有：DSR、BH、Bonferroni、PBO/CSCV（零假设是**日内打乱组合标签**，不是时间置换）、
  探索类只认注册之后的期次。
- 2026-09-06 新增 **试验记录** `ideagen/trials.py`：14 条，其中 3 条对比较表隐形
  （按评级排序＝试过没做成、用错字段的第一版动量、需要模型被排除的 ai_native）。
  `tests/test_trials_ledger.py` 在「注册了组合却没记进记录」时直接失败。
  多重检验的文案随之改成「一共试了 14 次（表上 11 个组合，另有 3 次不在表上）」。
- 2026-09-06 新增 **换一个 universe**：货架分四个风险家族，同一套规则各排各的。

```
整个货架 +0.231  (5/6 期为正)
股票     +0.075  (3/6, 每期中位 37 只)
商品     +0.076  (4/6)
债/现金  −0.055  (2/5)
```

**三分之二的排序力是家族之间的**——那是那个月的风险溢价，不是选股力。
与波动率证伪是两条完全独立的路径得到的同一结论。

**还没有**：留出集。6 期的时间维度上做不出真正的 validation sample，
目前的替代是「探索类只认注册之后的期次」。

## ⑤ 信号衰减、换手与成本

**论文**：一日反转同日收盘能做出 1.4 夏普，只能次日开盘交易就只剩 0.3；
换手约束会把夏普从 2.7 压到 1.8；但**换手受限 ≠ 该降低调仓频率**
（同样 36% 年换手，按月调比按年调多赚 1.5 倍）。

**本仓**
- 初心钉死 30 天 horizon、周跑、25% 分批——论文那条「频繁小幅调仓」支持这个设计。
- **成交现实（本轮新增）** `backtest.fill_reality`：回测按当期第一个收盘价无条件成交；
  当期实跑里唯一挂区间单的纸面组合 383 张成交 119 张（31%）。
  两个数必须一起读：**区间会挑**（成交 +2.98% vs 未成交 +1.62%，同一起点计价）、
  **但只有成交的钱在场**（组合层面 +1.14% vs 全成交假设 +2.04%，净亏 0.90pp）。
- **成本敏感性（本轮新增）** `perf.cost_sensitivity`：三档成本假设 × 本金倍数。
  同一常数在任何规模下都改不了排名（各组合周转相同）；按流动性分档，
  $10M 上动 2 个名次、$50M 动 7 个、$100M 动 10 个。
  档位是**声明**的假设不是拟合的系数，所以报的是「哪些结论依赖它」。

**还不能说**：没有冲击成本模型（`perf.capacity` 明确拒绝把参与度折成美元，
理由是没人拟合过系数——这条依然成立）。

## ⑥ 异常值、标准化，以及「超额相对谁」

**论文**：winsorize / IQR / 秩变换各有取舍；动量是例外，秩变换会丢掉距离信息
（实测掉 35% 预测力）；以及**基准选错会凭空造出漂移**（红利事件研究：
对着大盘看分红股公告前在漂，对着分红股看就没有）。

**本仓**
- 全站用分位与秩排序，天然抗异常值。若来日给 `mom_21` 做归一化，先想起论文那条例外。
- **基准（本轮新增）** `backtest.shelf_equal_weight_series`：货架自身等权、逐日再平衡。
  live 27 个交易日实测：**货架等权 +4.77% / 波动 8.04% / 夏普 5.00**，
  SPY +5.58% / 10.97% / 4.35——**货架是更高的那根杠**。
  两条都留着：SPY 回答「客户不如去买股票指数」，货架等权回答「选得比不选好吗」。
- 一处诚实边界：这条对照的成分是今天还在架上的标的，**自带幸存者偏差**，
  方向已知（退出的更差 ⇒ 真实历史更低），所以它是偏严的对照。

**还不能说**：27 个交易日两个基准都分不开任何一条组合——`separability` 与
`separability_vs_alt` 都是「没有任何一条被证明跑赢」。

## ⑦ 非对称 payoff 与做空成本

**论文**：价值类 alpha 在多头、动量/质量类在空头；难借的名字会吃掉集中组合的优势，
**去掉难借之后分散完胜集中**（25 名 1.5x → 800 名 2.2x 夏普）。

**本仓**
- 只做多 + 余钱买 JPST，做空成本 N/A。
- **多空拆分（本轮新增）** `backtest.payoff_asymmetry`：六期实测
  多头 +1.72% / 空头 +0.96% / 价差 +2.68% ⇒ **多头占比 64%**。
  引用 `top_minus_bottom_pct` 系统性高估可兑现部分约三分之一。
  2026-07-29 那期多头是 −0.01%，**整条价差全在不能碰的那一半上**。
- 集中 vs 分散：`ev_rank` 表现最好也最不可扩（容量 $17M vs buy_all $641M），
  而 ⑤ 的成本敏感性给了同一件事的第二个角度。

## 续篇：2026-09-06 下半场（证据页 reimagine + 量化做实）

### 页面：从仓库变成有脊椎

此前 12 张卡、约 53000px（25 屏），而**唯一一条候选发现要过的每一道检验，
分散在三张不同卡的折叠块里**。现在一张卡把它们串成一条：

**「这条发现，减到最后剩什么」**——九道检验，每行给数、给判定、指向细节卡。
规矩三条：每行必须有数（取不到写「没算」，因为消失和通过在界面上一样）；
判定只有 没扛住 / 打折 / 分不开 / 扛住了；漏斗只串不重讲。

```
表面：Q5 +3.13% vs Q1 +0.67%，两端差 +2.68%/期 [+1.70, +3.75]   看起来成立
减「只是在排风险」            控波动偏相关 +0.005 [−0.175, +0.218]  没扛住
减「只是把商品排在国库券之上」 家族内最高 +0.076 [−0.178, +0.316]   没扛住
减「压在少数标的上」          剔头部 10 只后 +1.50% vs 基准 +1.23%  没扛住
减「只做多拿得到的」          64.1% 可兑现                          打折
减「成交拿不到的」            成交率 31.1%，组合层面 −0.90pp        打折
减「盘子大了的成本」          $100M 上 10/11 换位                   打折
减「窗口没跑满的仓位」        满窗后领先从 +2.36% 收到 +1.22%       打折
减「一共试了多少次」          DSR 0.707                             没扛住
减「挑组合这个动作」          −0.41%/期 [−2.10%, +1.61%]            分不开
```

### 预注册：把「值得往前跑一段看看」变成可对账的承诺

`ideagen/prereg.py`。**估计量用路径钉死**，不是文字描述——下一轮真正的自由度
不在门槛上，而在「用哪个数」。门槛 8 期（两轮分批周期），到期前只报数不判定。
选哪条线本身就是这轮证伪的产物：原始阶梯样本内漂亮（区间不含 0），
但预注册钉在**控波动之后**那个数上，测试里有一条专门查这件事。

### 装上区间之后，两处结论被改口

按**期次**重抽，不按观测——同期内的观测被同一个月行情绑在一起，
按观测重抽会随货架变大而变窄，「更多标的」看起来像「更多证据」。

- **阶梯是真的**：Q5−Q1 +2.68%/期，[+1.70, +3.75] 不含 0。
- **它由风险构成**：控波动后 +0.005，[−0.175, +0.218] 盖住 0——
  这是「没有被证明存在」，不是「已被证明为 0」。
- **「跟随领先者跑输随机」我说过头了**：−0.41%/期，[−2.10%, +1.61%] 盖住 0。
  五次决策分不开。方向不变（挑选没有产出），但不能反过来声称已证明它有害。

### 一条自我更正：窗口完整度那一刀，第一版用错了统计单位

`_horizon_completeness` 直接遍历持仓行，而本仓别处（`ArmScore`、
`turnover_and_cost`、`capacity`、`cost_sensitivity`）早就按**标的×期**去重了——
同一只标的被四种生成方式提出就是四行，但只有一条价格序列。按行统计把 n 抬高约三倍，
并且把均值悄悄变成「按共识度加权」的平均：那是个可以辩护的统计量，但不是这一列
声称的那个，也不是同一页其它表用的那个。

去重之后这一刀的结论变了：

```
             去重前（想法行）        去重后（标的×期）
总仓位        3628 / 满窗 41.1%      1207 / 满窗 35.9%
ev_rank       +3.48 → 满窗 +2.45     +3.81 → 满窗 +4.11
对基准领先    +2.08% → +0.11%        +2.36% → +1.22%
名次变化      11 条全换               7 条换位，ev_rank 仍第一
```

所以那一行的判定从「没扛住」改成「**打折**」：优势缩水一半但还在，
而且满窗子样本只剩 8 笔。判定因此改成三档（没扛住 / 打折 / 扛住了），
免得「缩水一半」被四舍五入成两端里的任何一端。

### 这半场我自己造并修掉的三个缺陷

1. **漏斗第一版把判定印反**：读 `walk.random_mean`——字段不存在，缺失值被当成 0，
   「+0.59% vs 随机 0.00%」印成「扛住了」，真实对照是 +1.00%。修法双份：
   判定统一走 `vd()`（任一输入为 null 印「没算」）+ 闸门
   `FunnelReadsFieldsThatExist`（漏斗读的每个字段必须真由后端写出；注入法验过会红）。
2. **回测在落库前崩掉而面板照旧**：`.items()` 遍历一个混着 float 的字典，
   异常发生在 summary 建好之后、写库之前。**「回测没变化」和「回测崩了」
   在界面上长得一模一样**——是查库不是查 API 才看见的。回执因此补上产出时间
   与「最近一期还没进这次回测」的落后标记。
3. **页面第一屏说反**：总账第⑤行（页头那句话由它生成）写的是「分数排得动结果」，
   而排的是风险。已改成「排得动，但排的是风险」。

## 我自己在这一轮踩的坑（形状比结论有用）

1. **成交率从「能计价的订单」里算** → 所有组合都报 100% 成交，因为 pending 单全是最近下的、

   （这套系统的实盘通道是故意没接的），要写「当期实跑」。
